Zero Trust Principle
All access authenticated via Azure AD. No standing privileged access — JIT access for production via Privileged Identity Management (PIM). All traffic encrypted TLS 1.2+. Service principals for all pipelines — PATs forbidden in production. MFA mandatory for all human accounts.
🔐
Identity & Access
  • Azure AD (Entra ID) — centralised IdP for all MRx services
  • Managed Identity (MSI) for all service-to-service auth — no stored credentials
  • Least-privilege RBAC via Unity Catalog and Azure AD
  • Privileged Identity Management (PIM) — just-in-time elevated access
  • Quarterly access reviews — stale permissions removed automatically
  • MFA mandatory for all human accounts
Entra IDPIMRBAC
🌐
Network Security
  • VNet injection — all Databricks workspaces in customer-managed VNets; no public IP
  • Private endpoints for ADLS, Key Vault, and ACR
  • Network Security Groups with deny-all default + explicit allow rules
  • Azure Firewall with FQDN-based outbound allowlisting
  • DDoS Protection Standard on production virtual networks
  • Network flow logs captured to Log Analytics for forensic investigation
VNetPrivate Endpoints
🗝️
Secrets & Key Management
  • Azure Key Vault — centralised secret, key, and certificate management
  • Databricks Secret Scopes backed by Key Vault — no secrets in notebooks or code
  • Key rotation policy: credentials rotated every 90 days automatically
  • Soft-delete and purge protection on all production Key Vaults
  • Certificate expiry monitoring: alerts raised 30 days before expiration
  • GitHub Secrets for CI/CD credentials — never hardcoded in workflow files

🔎 Vulnerability Management — Panorama
Centralized vulnerability tracking, triage, and remediation platform
Panorama Scope Vulnerability findings from all MRx platform components — Wiz, GitHub GHAS, SonarQube — are ingested into the enterprise Panorama vulnerability management platform for centralized tracking, risk scoring, and SLA enforcement.
📡
Panorama Integration
  • Wiz and GitHub Security findings auto-ingested into Panorama via API connectors
  • Findings deduplicated and correlated across multiple scanners
  • CVE enrichment: CVSS scores, exploit availability, and asset criticality weighting
  • Risk-based prioritisation: findings ranked by exploitability × asset sensitivity
  • Panorama ticket auto-assigned to responsible engineering team
  • Critical CVEs resolved within 72 hours
  • Monthly vulnerability posture report to Tech Lead and CISO

☁️ Wiz Cloud Security Monitoring
Continuous Cloud Security Posture Management (CSPM) and Cloud Workload Protection (CWPP)
Wiz Deployment Scope Wiz is deployed across all MRx Azure subscriptions with agentless scanning. It continuously assesses the security posture of every Azure resource, container image, and Databricks cluster — providing a real-time risk graph of the entire MRx platform. Daily scan cadence.
🔭
CSPM — Cloud Security Posture
  • Continuous misconfiguration scanning across all Azure resources (storage, network, identity)
  • Checks against CIS Azure Benchmarks and McKinsey internal security policy
  • Publicly exposed storage accounts → Critical finding + immediate alert
  • Overly permissive IAM roles detected and flagged for remediation
  • Unencrypted disks and data flagged as High severity
  • MFA enforcement check on all human identity accounts
  • Wiz Security Graph: visual risk path from internet-exposed resource to sensitive data
  • New resources scanned within minutes of provisioning
CSPMCIS Benchmark
🐳
CWPP — Workload Protection
  • Container image scanning in ACR — vulnerabilities detected before deployment
  • Kubernetes (AKS) workload assessment: pod security, privileged containers, host path mounts
  • OS vulnerability scanning: known CVEs in cluster node operating systems
  • Runtime threat detection: anomalous process execution, suspicious network calls
  • Databricks cluster node assessment via Wiz agentless scan
  • Secrets in environment variables or container filesystems detected and alerted
  • Software Bill of Materials (SBOM) generated for all deployed container images
CWPPSBOM
🔗
Wiz Custom Rules (MRx-Specific)
  • Custom rule: storage accounts must have public access disabled
  • Custom rule: Databricks clusters must not use public IP (NPIP enforcement)
  • Custom rule: Key Vault must have soft-delete and purge protection enabled
  • Custom rule: all resources must have mandatory tags (Owner, CostCenter, Environment)
  • Custom rule: no PATs in production Databricks configurations
  • Rule changes require CoE security review and PR approval before activation
Custom RulesPolicy as Code

🔍 GitHub Advanced Security (GHAS)
Secret scanning, SAST code scanning, and dependency review integrated into the developer workflow
GHAS Scope GitHub Advanced Security is enabled on all MRx repositories. Critical findings block PR merge. SAST and dependency scan results are exported to Panorama. Triaged within 24 hours by the responsible engineering team.
🔑
Secret Scanning
  • Enabled on all MRx repositories — push and historical scan
  • Detects: API keys, connection strings, Azure SAS tokens, PATs, OAuth tokens
  • Custom patterns for McKinsey-specific credential formats
  • Push protection blocks commits containing detected secrets before they reach the repo
  • Secret alerts routed to Security team inbox and repository owner
  • Detected secrets treated as compromised — rotated within 1 hour (P1 response)
Secret ScanPush Protection
🔬
Code Scanning (CodeQL SAST)
  • CodeQL static analysis on every PR and push to main
  • Languages: Python, JavaScript/TypeScript, SQL, HCL (Terraform)
  • Detects: SQL injection, XSS, path traversal, insecure deserialization, SSRF
  • Custom CodeQL queries for MRx-specific security anti-patterns
  • Required status check — Critical/High findings block merge
  • Scan results exported to Panorama via GitHub API connector
CodeQLSAST
📦
Dependency Review & Dependabot
  • Dependency Review Action runs on every PR — blocks merging of vulnerable packages
  • Covers: Python (pip), Node.js (npm), Terraform, Docker base images
  • Dependabot: automated PRs to update vulnerable dependencies within 24 hours
  • High/Critical Dependabot alerts assigned to on-call engineer for expedited review
  • SCA reports included in monthly security dashboard
DependabotSCA
⚙️
Additional Security Tooling in CI/CD
  • tfsec / checkov — Terraform security scanning in IaC PR pipeline
  • trivy — container image scanning before ACR push
  • Security scanning jobs run in parallel to test jobs — no pipeline duration impact
  • GHAS results surfaced inline in PR diff view for developer awareness
  • SonarQube quality gate: 0 critical bugs, 0 vulnerabilities, >80% coverage

🔔 Monitoring & Alerting for Compromised Data
Detection, response, and containment for data security incidents
👁️
Data Exfiltration Detection
  • Wiz + Azure Sentinel: automated detection of anomalous data access patterns, exfiltration indicators, and privilege escalation
  • Azure Defender for Storage: anomalous access pattern detection (volume, geo, time)
  • Unity Catalog audit logs: all data access events logged to Log Analytics
  • Databricks IP access lists: connections from unexpected IPs trigger alert
  • Microsoft Purview DLP: sensitive data classification and exfiltration prevention
  • Outbound data transfer volume monitoring: alert on bulk export exceeding threshold
  • Azure Sentinel UEBA: User Entity Behaviour Analytics for insider threat detection
